# Shedflare Money

A simple monthly budgeting ledger — track income and expenses with recurring templates and manual entries. Supports USD and IDR with currency conversion.

## Features

- **Monthly ledger**: Browse any month with prev/next navigation
- **Recurring templates**: Set up monthly items (rent, salary, subscriptions) and toggle them on/off per month
- **Manual entries**: Add one-off income or expenses with date, category, and notes
- **Currency conversion**: View all amounts in USD or IDR with a configurable exchange rate
- **Summary bar**: See income, expenses, and balance at a glance
- **Mobile-first**: Responsive design that works great on phones
