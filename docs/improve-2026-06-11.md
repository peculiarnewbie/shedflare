## Direction options

1. Decide whether the deprecated CLI is the Alchemy onboarding front door or should be reduced/retired. Evidence: `AGENTS.md:26` calls CLI deprecated, while `README.md:8` and `README.md:46` still present it as the main setup tool; `packages/cli/src/core/manifests.ts:6` omits `youtube` while `packages/shedflare-alchemy/src/config.ts:5` includes it. Tradeoff: reviving it is M-L effort; retiring it is smaller but requires docs and command-surface clarity.
2. Turn Observability from ingestion-only into an owner-facing error console. Evidence: `apps/observability/shedflare.app.jsonc:5`, root tail wiring at `alchemy.run.ts:59`, fetch currently only says “This worker only processes tail events” at `apps/observability/src/worker.ts:30`, and structured logs exist at `apps/observability/src/db/schema.ts:15`. Tradeoff: useful and additive, but must be owner-auth gated because it exposes stack traces.
3. Resolve Money’s documented DO/WebSocket vision vs current D1/REST implementation. Evidence: `apps/money/docs/deployment.md:7` says no D1; `apps/money/alchemy.run.ts:23` provisions D1; `apps/money/src/server/router.ts:40` is HTTP API over `MONEY_DB`. Tradeoff: either clarify/stabilize D1 REST now, or plan a much riskier DO/sync migration.
4. Add Drive trash/undo as a safety feature. Evidence: deletion currently removes R2 and DB immediately at `apps/drive/src/server/impl/files.ts:300`, and Drive planning notes defer undo until soft-delete exists. Tradeoff: high personal-storage value, but changes deletion semantics and retention policy.

## Considered and rejected

- Tracked secret-like files: `git ls-files` found no currently tracked `.env`, `shedflare.config.jsonc`, `apps/auth/keys.json`, `.dev.vars`, or app `wrangler.jsonc` files. Historical churn still mentions `apps/auth/keys.json`, but current tree evidence does not support a current-secret finding.
- Wrangler subprocess usage in the deprecated CLI is not itself a command-injection finding because arguments are passed as arrays through `nano-spawn`; the actionable issue is secret collection/exposure, not spawning.

## What was not audited

I did not run live Alchemy smoke tests, e2e tests, dependency audit, or Cloudflare deployments. I avoided secret-bearing local files. I did not do a full line-by-line audit of every frontend component.
